# Now Playing test fixtures

Original placeholder lyrics written for these tests (no real song lyrics, docs/NOWPLAYING_PLAN.md).
The fake MPRIS player in `nowplaying-test@local` serves them as `.lrc` files next to its made-up tracks.

- `paper-lanterns.lrc`: synced lines with a gap (an instrumental break).
- `plain.lrc`: unsynced text only, which counts as no lyrics (the column is centred).
